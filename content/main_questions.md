# 九型人格地图270题母题库 v3

## 1. 使用定位

本题库用于“九型人格地图”H5测试的第三版母题库。90题标准版与180题专业版共用同一套270题母题库，通过分层抽题生成，不再维护分离题库。

设计目标：

1. 不照搬市面上的版权题库，全部为原创表述。
2. 支持生成九型1-9号元素分数。
3. 支持正向题、反向题、情境校验题混合。
4. 支持后续做题目质量分析、题库迭代和老师复核。

## 2. 作答方式

用户端统一采用3级选项，底层仍保存为1/3/5分值，便于与“否/不确定/是”图表顺序保持一致。

```text
1 = 否
3 = 不确定
5 = 是
```

## 3. 计分方式

| 题型 | 计分 |
|---|---|
| 正向 | 元素得分 = 用户选择分 |
| 反向 | 元素得分 = 6 - 用户选择分 |
| 情境 | 元素得分 = 用户选择分，同时作为场景校验题 |

后台仍需保存原始答案，不要只保存换算分。历史5级答案仍可被后台兼容解析，但用户端新作答只出现1/3/5三档。

## 4. 题目字段

| 字段 | 说明 |
|---|---|
| ID | 题目编号 |
| 元素 | 对应九型元素 |
| 题型 | 正向/反向/情境 |
| 维度 | 核心动机、核心恐惧、注意力焦点、防御机制、关系模式、工作模式、情境校验、反向校验等 |
| 题目 | 用户看到的题干 |
| 计分 | 正向/反向/情境 |

## 6. 抽题规则

270题母题库：作为唯一主型题库，不直接给用户一次性全量作答。

180题专业版：从270题母题库中分层抽取，每型20题。

90题标准测试建议：

```text
每型从270题母题库中抽10题：
- 正向题5题
- 反向题3题
- 情境题2题
- 每型至少包含1道防御机制题

九型合计90题。
题目全局随机排序。
同一元素题目不得连续出现超过2题。
反向题不得连续出现超过3题。
```

## 7. 质量校验规则

### 7.1 作答质量

| 情况 | 标记 |
|---|---|
| 答题时间明显短于合理时长 | speed_risk |
| 80%以上题目选择同一分值 | straight_line_risk |
| 3分占比超过45% | uncertainty_risk |
| 5分占比超过55% | over_agree_risk |
| 1分占比超过55% | over_deny_risk |

### 7.2 正反向一致性

每型正向题均值与反向题换算均值差距超过1.5分，标记：

```text
reverse_consistency_risk
```

处理方式：

- 不直接判无效。
- 降低该元素置信度。
- 在老师端提示需复核。

### 7.3 高分接近

如果前三名元素得分差距均小于5%，不输出唯一主型，只输出：

```text
高分群组
核心动力待验证
建议老师访谈确认
```

## 8. 题库审核清单

每次修改题库时检查：

- 每型是否保持30题？
- 每型是否包含15正向、9反向、6情境？
- 是否存在过于直白、容易猜类型的题？
- 反向题是否写得清楚，不绕、不双重否定？
- 题目是否避免病理化、羞辱化、价值评判？
- 是否覆盖核心动机、核心恐惧、注意力焦点、防御机制、关系模式、工作模式、情境校验？
- 是否保留原始答案以便后续校准？
- 是否经过至少20个真实样本内测？

## 9. 待内测校准

此题库为v3版本。正式使用前建议做三轮校准：

1. 内部老师试测：检查题目是否准确对应元素。
2. 熟人样本试测：找已知主型的人测试，观察命中率。
3. 陌生用户试测：观察题目理解、完成率、结果共鸣度。

每轮记录：

```text
题目理解问题
高频误判元素
正反向冲突题
用户觉得被看见的句子
用户觉得不准或冒犯的句子
```
